# Home Appliance Scheduling Tool (Python based - Electrical Appliance Optimisation)
Python based home electrical appliance scheduling optimisation tool. This tool takes user inputs of energy demand, generation and cost as well as appliance energy usage data to optimise appliance run times/scheduling.
